Privacy Policy — AI Shorts Factory

Effective date: October 15, 2026

What this application is

AI Shorts Factory is a personal automation tool run by a single operator. It creates short videos and uploads them to the operator's own YouTube channel through the YouTube API Services, using the following OAuth scopes: https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube.readonly.

Data accessed

The application accesses only the operator's own YouTube channel: it uploads video files and metadata (title, description, tags, privacy status) prepared by the operator, and reads back the operator's own video metadata to verify that each upload was registered correctly. It does not access data belonging to any other person or channel.

Data stored

OAuth access and refresh tokens are stored locally on the operator's own computer, in a file readable only by the operator's account. No data is transmitted to, stored on, or processed by any third-party server other than Google's own API endpoints, which are required for the uploads themselves.

Data sharing

No personal data is collected from end users, because the operator is the only user. No data is sold, shared, or disclosed to third parties.

Revoking access

The operator can revoke the application's access at any time from the Google Account permissions page (myaccount.google.com/permissions), which immediately invalidates the stored tokens.

Contact

Questions about this policy can be sent to the developer contact email registered for this application in Google Cloud Console.
